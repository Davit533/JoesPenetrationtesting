# JoesPenetrationtesting

A Python-based penetration testing and utility tool featuring a modern PySide6 graphical user interface.

## Features

* Modern GUI built with PySide6
* Built-in helper utilities and API integrations (`FAPI`)
* Memory manipulation and process monitoring via `pymem` and `psutil`
* Automated mouse/keyboard control capabilities
